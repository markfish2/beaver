# 全局外观系统

## 设计方向

界面采用温和、克制、内容优先的视觉语言：避免纯白与纯黑的大面积强反差，通过相邻表面的细微明度差建立层级，以暖陶土色作为主要强调色。主题不是单个内容页的背景，而是一组覆盖画布、表面、文字、边框、代码、引用、链接和选区的语义令牌。

## 内置主题

| 设置值 | 名称 | 用途 |
| --- | --- | --- |
| `system` | 跟随系统 | 随设备深浅模式切换，不覆盖账号偏好 |
| `minimal` | 亚麻纸 | 中性暖白，适合长期写作 |
| `warm` | 暖沙 | 更低刺激的暖色阅读环境 |
| `dark` | 深炭 | 避免纯黑，降低夜间眩光 |
| `geek` | 雾蓝 | 冷静、清晰的轻技术风格 |

## 语义令牌

- `--app-canvas`：应用最底层背景
- `--app-surface`：侧栏、内容页、卡片和弹窗
- `--app-surface-raised`：浮层与强调表面
- `--app-code-bg` / `--app-code-text`：代码区域
- `--app-quote-bg` / `--app-quote-border`：引用区域
- `--app-link`：正文链接
- `--app-selection`：文本选区
- `--color-gray-50` 至 `--color-gray-950`：全应用中性色阶

## 同步规则

账号中的 `theme`、`font_family`、`font_size` 是权威值，本地缓存只用于首屏无闪烁和网络失败兜底。用户在个人资料中修改后立即应用，并通过 `/api/users/settings` 写入账号；重新登录或在其他设备打开时以账号值恢复。

只有 `system` 响应 `prefers-color-scheme`。明确选择其他主题后，操作系统模式变化不会覆盖用户选择。

## 功能归位

- 大纲笔记右上角：思维导图、导出、分享、保存状态。
- 普通笔记右上角：导出、分享，以及原有编辑/阅读切换。
- 主题、字体和字号：个人资料中的“外观与主题”。
- 原可折叠顶部入口和综合文档设置菜单不再使用。
